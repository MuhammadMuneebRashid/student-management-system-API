# Student Management System (REST API)

A simple Python-based Student Management System that demonstrates how to perform REST API operations using the `requests` library. The project allows users to register, update, and delete student records through the JSONPlaceholder API.

## 🚀 Features

- Register a new student (POST)
- Update student information (PUT)
- Delete a student record (DELETE)
- Menu-driven command-line interface
- Error handling using `try-except`
- JSON data handling
- HTTP status code validation

## 🛠️ Technologies Used

- Python 3
- Requests Library
- JSONPlaceholder REST API

## 📂 Project Structure

```
Student-Management-System/
│── student_management.py
│── README.md
```

## ▶️ How to Run

1. Install the `requests` library:

```bash
pip install requests
```

2. Run the program:

```bash
python student_management.py
```

## 📖 API Operations

- **POST** – Register a new student
- **PUT** – Update existing student information
- **DELETE** – Remove a student record

> **Note:** This project uses the JSONPlaceholder fake REST API for learning and practice purposes. The API simulates CRUD operations and does not permanently save changes.

## 🎯 Learning Objectives

- Working with REST APIs in Python
- Sending HTTP requests using the `requests` library
- Handling JSON data
- Exception handling
- Building menu-driven Python applications
